Get your first project online

  1. Add your local folder. Choose Add project, then select the folder to upload. For a built website, choose its build or dist folder.
  2. Connect your hosting. Enter your FTP, FTPS, or SFTP details, or load DEVSYNC_* settings from the folder’s .env. Test the connection to continue.
  3. Choose the server folder. Browse to the destination, select Use server folder, review, and save.
  4. Preview, then deploy. Preview uploads shows the planned files. Deploy uploads all eligible files; Sync uploads changed files. Watch follows subsequent saves while DevSync runs.

Common questions

How do I change a project’s local folder or hosting settings?

Open the saved project and choose Edit setup. Change or browse for the local folder, review your hosting settings and destination, then save. Stop any active watch or upload before editing.

Why can’t I connect to my hosting?

Confirm the host, protocol, port, username, and credentials with your hosting provider. FTP and FTPS usually use port 21; SFTP usually uses 22. If your ISP blocks port 21, ask your host whether SFTP or an alternative port is available. The server must support the protocol and port you choose.

Why are my changes not uploading?

Check the selected local folder and server destination. Use Preview uploads to see which files are included or excluded, check whether Preview only is enabled, and open the Activity log for errors. Watch requires DevSync to remain running.

Which settings take priority?

Settings in the selected folder’s .env take priority over .devsync.env and saved settings. If an edit appears to revert, check those files. DevSync does not rewrite your application’s environment files.

Are credentials and server files protected?

Saved credentials are encrypted on this computer. Environment files and other protected files are excluded from deployment. Local deletions are never mirrored to the server. Preview uploads before deploying to confirm your destination and file list.

Can I use DevSync from a terminal?

Run devsync help for commands, devsync ui for this dashboard, or devsync doctor to check your local installation. The shared-hosting-sync command works as an alias.

Need a hand? Email the creator or report an issue with the error message and your DevSync version. Keep passwords and private keys out of reports.
